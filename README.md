styled-components против CSS Modules

В проекте я использовал styled-components, так как удобно хранить стили рядом с компонентами, сразу все видно. Через ThemeProvider я сделал переключение темы без передачи объекта темы через пропсы. Типизация DefaultTheme контролирует доступные значения темы на уровне TypeScript. При реализации разных вариантов кнопок использовал transient props и функцию css. При использовании CSS Modules пришлось бы отдельно хранить CSS файлы и выбирать классы в зависимости от пропсов компонента. При этом CSS Modules не требуют генерации стилей во время выполнения приложения. В итоге styled-components удобнее, особеенно при создании переиспользуемого UI кита с поддержкой тем.
